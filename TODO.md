# The CFO Game — Outcome Checklist

## Opening experience and company snapshot
- [x] Opening game screen presents the title “THE CFO GAME — Run a Company Without Going Bankrupt”, the tagline “You have ₹100 crore. Don't waste it.”, the CFO role, and the starting financial position: Revenue ₹100 crore, Net profit ₹5 crore, Debt ₹60 crore, Cash balance ₹8 crore.
- [x] A persistent financial dashboard shows Revenue, Net profit, Debt, Cash balance, and updated company health as the player progresses.

## Round 1 — Raise Capital
- [x] The player can choose between Borrow from a bank, Issue new shares, or Use retained earnings.
- [x] The selected capital decision creates immediate financial consequences reflected in the dashboard and feedback.

## Round 2 — Manage Working Capital
- [x] The player sees a cash-flow problem and can choose Reduce inventory, Negotiate longer payment terms with suppliers, Offer customers shorter credit periods, or Arrange additional short-term financing.
- [x] The selected working-capital decision creates immediate financial consequences reflected in the dashboard and feedback.

## Round 3 — Investment Decision
- [x] The player can compare two projects with distinct costs, cash flows, risks, and expected returns.
- [x] The website calculates and displays each project's NPV, compares the results, and records the selected project.

## Round 4 — Results and replay
- [x] The results evaluate Profitability, Liquidity, Debt levels, Return on investment, and Shareholder value based on accumulated decisions.
- [x] Decision feedback explains trade-offs and consequences after each choice and provides a final narrative assessment of the CFO performance.
- [x] The game supports round indicators, validation, restart/play-again controls, and a coherent responsive desktop/mobile flow.
- [x] The application is Vercel-compatible and the finished code is delivered to the connected GitHub repository `rigved2407-arch/Finance-management-`.
